## 3. Протоколы взаимодействия

### Протокол ITaskService

Участники: ViewModels → Services.
Назначение: получение и изменение задач.
Методы: GetAll, GetById, Add, Complete, Delete.
Формат данных: объекты C# класса Task, хранение в Microsoft SQL Server через Entity Framework.
Соглашения: асинхронные методы возвращают Task, имена методов — глагол и существительное.

### Протокол IReminderService

Участники: ViewModels, ReminderScheduler → Services.
Назначение: создание напоминаний и выдача просроченных.
Методы: Schedule, GetDue.
Планировщик ReminderScheduler проверяет напоминания каждые 30 секунд.

### Протокол INotificationService

Участники: Services → операционная система.
Назначение: показ уведомлений Windows.
Метод: Show.

### Протокол привязки данных

Участники: Views ↔ ViewModels.
Назначение: автоматическое обновление интерфейса.
Соглашения: модели представления реализуют INotifyPropertyChanged, разметка XAML
использует Binding, коллекции обёрнуты в ObservableCollection.

### Протокол команд

Участники: Views → ViewModels.
Назначение: вызов действий интерфейса без обработки событий в коде окна.
Соглашения: команды реализуют ICommand через RelayCommand.

## 4. Соглашения об именовании и версионировании

- классы, интерфейсы и методы — PascalCase;
- приватные поля — _camelCase;
- окна — суффикс Window, модели представления — ViewModel, сервисы — Service;
- интерфейсы начинаются с префикса I;
- пространства имён повторяют структуру каталогов;
- ветки Git: main, feature/краткое-имя, fix/краткое-имя;
- сообщения коммитов: тип: описание, например feat: добавлено редактирование задач;
- версионирование SemVer: мажорная.минорная.патч.
